---
name: prd-to-local-implementation-plan
description: >
  Mirrors a Linear issue's PRD into the local plans folder and adds a task to
  progress.yaml so it can be implemented in a sandboxed local agent run. Use when asked
  to pull a Linear issue down for local implementation or to queue a ticket on the local
  backlog.
---

1. Download the PRD for a given Linear issue to the plans folder for sandboxed local development.
2. Add a new task to progress.yaml for implementation of this issue.
